# Instaby App

Painel interno da Instaby Agência — v12.

## O que entrou nesta versão

- **Cor de destaque voltou a ser vermelho** (#E63946), como sempre foi a
  marca de verdade — troquei o amarelo em todo o app: botões, ícones
  ativos, pílulas selecionadas, gráficos do Financeiro, página pública do
  orçamento. Texto sobre o vermelho também mudou de preto pra branco (mais
  legível nesse contraste).
- **Logo real da Instaby** — extraí o logo do PDF que você mandou e ele
  está em `public/logo.png`. Substituí o texto estilizado "instaby" pela
  imagem de verdade em: sidebar, tela de login, página pública do
  orçamento e no preview ao vivo do construtor de orçamento.

## Nada de estrutura mudou

Só cor e a troca do texto pela imagem do logo — nenhuma tabela, API ou
lógica foi alterada nesta versão.
