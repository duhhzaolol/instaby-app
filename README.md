# Instaby App

Painel interno da Instaby Agência — v11.

## O que entrou nesta versão

- **Despesa com data desde a criação**: antes só dava pra editar a data
  depois; agora o formulário de nova despesa já pergunta a data, então dá
  pra lançar retroativo (ex: os últimos 3 meses) direto na criação.
- **Ocultar valores**: botão de olho no topo da Visão Geral — clica e todo
  valor em R$ vira "••••••". Fica salvo (mesmo se recarregar a página),
  pra quando tiver alguém por perto.
- **Visão Geral virou foco em afazeres**, do jeito que você usava o
  Notion:
  - Barra de captura rápida no topo — digita o que precisa fazer, escolhe
    o cliente (opcional) e adiciona. Não precisa mais entrar no cliente
    pra anotar uma tarefa.
  - Lista de afazeres embaixo, com o cliente marcado em cada um (quando
    tiver), pra você organizar com calma depois, no PC.
  - Concluídas ficam escondidas por padrão (clica pra expandir).
  - Os números financeiros ainda aparecem no topo (Clientes ativos, Leads,
    Faturamento do mês, Cobranças pendentes) mas pequenos, sem gráfico —
    os gráficos completos continuam em Financeiro.
