# Instaby App

Painel interno da Instaby Agência — v34.

## O que entrou nesta versão

**Calendário de horas por cliente** — clicar no card de um cliente na
tela de Horas agora abre `/dashboard/horas/[cliente]`: um calendário
mensal só daquele cliente, com os dias trabalhados destacados (fundo na
cor do cliente), mostrando quantas horas e quais atividades foram feitas
naquele dia. Dá pra navegar entre os meses com as setinhas, igual na
Agenda geral — serve pra conferir rapidinho se bateu tudo certo antes de
fechar o mês.
